# artifacts

Source material and the working record.

- `Curated Inventory of Cellular Automata.md` — the 45 entries: types, looks,
  starts, and the CPU `Program` source. `Core/Catalog` and `Core/Programs` are
  built from this.
- `System prompt_ rating inputs as simple, structured, random, or complex.md` —
  the rating rubric. `Core/Agent/SystemPrompt.swift` embeds it with the design
  doc's edits.
- `Implementation Log.md` — the running status/history record **and the design
  of record carried forward** from the draft v0.4 design doc (architecture,
  agent, catalog, UI, render, persistence, setup, testing, milestones, the
  open decisions, and the verification table). This file is **outside the
  README chain** on purpose: it is the one place for status, decisions, and
  deviations, so the READMEs can stay durable and free of history (see
  `AGENTS.md`, "README documentation policy").
